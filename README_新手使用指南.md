## ❓ 常见核心疑问答疑

### 问：“无论什么时候我都能在浏览器打开 `http://localhost:5173/` 吗？是写死在电脑上了吗？”

**答：不是直接永久能打开，但你的代码确实永久保存在你的电脑上了！**

可以这样理解：
* `http://localhost:5173/` 不是一个互联网上的公共网站，而是你电脑自己给自己搭建的一个**“临时小展台”**（本地开发服务器）。
* **代码确实已经写死在你的电脑硬盘里了**（就在你的 `D:\Gemini pro\Retro Hardware Cyberpunk Terminal` 文件夹内），即使断网、重启电脑，文件一个都不会少。
* **但是**，这个临时小展台（服务器）需要**“通电营业”**。
  - **当前状态**：我现在已经在后台帮你把服务打开了，所以你现在立刻在浏览器打开 `http://localhost:5173/` 就能看到它！
  - **关机/重启之后**：如果以后你关了电脑或者退出了软件，这个展台就休眠了，直接访问就会显示“无法访问此网站”。
  - **怎么再次打开？** 非常简单！我为你做了一个**“一键开机按钮”**。

## 🚀 以后怎么随时打开它？（极简两步）

进入你的项目文件夹：`D:\Gemini pro\Retro Hardware Cyberpunk Terminal`：

1. **直接双击** 文件夹里的 **`启动终端.bat`** 脚本。
2. 电脑会自动弹出一个黑色小窗口启动服务，并且**自动帮你打开默认浏览器**弹出终端界面！
3. **不用的时候**：直接把那个黑色小窗口关掉即可。

## 🕹️ 终端各项功能怎么玩？

当你打开页面后，会看到一个非常硬核的 80 年代机械设备：

### 1. 开机（冷启动总闸）
* 刚进去时，屏幕会显示 **`TERMINAL OFFLINE`**（终端离线）。
* 找到左侧写着 **`MAIN POWER BREAKER`** 的重型电源总闸，**点击那个红绿金属拨杆**。
* **效果**：
  - 会听到超逼真的**大电容充电升频音 + 机械继电器咔哒声**！
  - 屏幕中央会像老式电视机一样，自一条水平亮线瞬间展开！
  - 上方绿色的 **PWR** 和青色的 **CARRIER** 指示灯点亮。

### 2. 打字与实时转换
* 终端已经为你准备好了一段示范文字，你可以在上面的输入框随意打字（比如输入 `Hello World` 或中文）。
* **打字音效**：每次敲击键盘，都会发出 80 年代 IBM 机械键盘的清脆咔哒声。
* **实时输出**：下方输出框会秒级把你输入的文字转成 **十六进制代码（HEX）**，右侧还会显示古董终端的 ASCII 转储和内存偏移量！
* **指示灯闪烁**：打字时，上面的 **RX/TX 黄色信号灯** 会高速频闪。

### 3. 玩法与转换模式切换
在左侧的 **CODEC MODE** 模块，你可以点击任意模式：
* **TXT → HEX**：文本转十六进制（带标准 8 位内存偏移与 ASCII 转储）。
* **HEX → TXT**：十六进制逆向解码回正常文本。
* **TXT → B64**：文本转 Base64 编码。
* **B64 → TXT**：Base64 解码。
* **TXT → MORSE**：文本转摩尔斯电码（点 `.` 和 划 `-`）。
* **MORSE → TXT**：摩尔斯电码反解。
* **TXT → BIN**：文本转二进制 8-bit 比特流（`01001000 01100101...`）。
* **BIN → TXT**：二进制比特流反解回明文。
* **ROT-13 CIPHER**：经典密码学 13 位字符移位加密与破解。
* **[SWAP ⇄] 按钮**：一键把输出内容换到输入框，并自动对调转换模式。

### 4. 双轨仪表舱：无线电示波器 + 机械阻尼模拟 VU 电平表
* **实时波形示波器（RF SIGNAL MONITOR）**：通过真正的 Web Audio 分析器连接，打字、发报或按键时，真实声波波形在屏幕上实时跳动，空闲时会有微弱的高频环境载波。
* **模拟指针 VU 表（ANALOG VU METER）**：采用物理弹簧阻尼算法，指针随音频音量实时摆动；当音量过大或突发大信号时，右侧的红色 **PEAK** 警报指示灯会瞬间爆闪！

### 5. 无线电摩尔斯音频发报与 44.1kHz WAV 一键导出
* **发报调速（RATE）**：可在下拉框中自由选择发报速度：
  - `10 WPM`（慢速侦察电台）
  - `18 WPM`（标准业余无线电速率）
  - `26 WPM`（军工高速突发发报）
* **► AUDIBLE TRANSMIT**：点击向扬声器发射纯正 750Hz 莫尔斯电码短音与长音，示波器与 VU 表剧烈联动！中途再次点击可立即中止。
* **💾 EXPORT WAV**：**直接下载纯音频文件！** 零服务器参与，浏览器纯代码算法合成高质量 44.1kHz 16-bit PCM RIFF `.wav` 声音文件并自动下载保存到你的电脑中！
* **📄 EXPORT TXT**：一键将当前时间、输入流、输出流、CRC32 校验码与 XOR 摘要导出为排版精致的 `.txt` 军用电传报告！

### 6. 五款荧光显像管色彩 + CRT 3D 弧面曲率切换
在屏幕顶部的 **PHOSPHOR COLOR** 区域：
* **P1-GRN**：经典黑客绿显像管。
* **P3-AMB**：工业琥珀金（暖黄工业风）。
* **P4-CYN**：冷光赛博青（科幻蓝）。
* **P4-WHT**：80 年代黑白单色显像管（Paper White Monochrome）。
* **P2-RED**：高危等离子警报红（Plasma Alert Red）。
* **[CURVE: ON / OFF]**：点击可一键开启/关闭 CRT 老式球形弧面玻璃凸起与桶形暗角滤镜！

### 7. 数据发生器（假装黑客）
左侧还有两个好玩的数据发生按键：
* **GEN HEX DUMP**：瞬间随机生成 64 字节内存转储矩阵，看起来就像在渗透一台主机。
* **TELEMETRY PKT**：生成一份带有微秒时间戳、加密密钥和温度的工业遥测数据包。

### 8. 保存历史记录（LOCALSTORAGE LOG）
* 点击 **`[STORE LOG]`** 按钮。
* 当前的转换结果就会被带时间戳永久存在浏览器的本地空间里。
* 在下方列表点击 **`[RECALL]`**，可以随时一键把以前记录重新调回到终端里！

## 🔊 声音常见问题

* **如果打开没有声音怎么办？**
  - 现代浏览器（Chrome、Edge 等）有安全策略，必须等你在网页上**点一下鼠标**，才允许网页出声。
  - 请确保右上角的声音滑块没有被拉到最左边，以及没有点击 **MUTE（静音）** 按钮。
  - 开机时点击左侧的电源总闸，就会立刻激活声音引擎！
