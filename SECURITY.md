# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| < 1.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or sensitive data leakage within this project, please report it responsibly rather than opening a public issue.

Please send an email to the repository maintainer at **254672829@qq.com** with details about:
- The type of vulnerability
- The steps required to reproduce the issue
- Potential impact and suggested mitigations

We will review your report within 48 hours and work on a fix promptly.
